======================================
GET /api/threads
======================================

Get all the threads in the platform.

REQUEST:
empty body

RESPONSE:
200 OK
[
	{
		"threadId": 2,
		"threadName": "Coding",
		"postCount": 67
	},
	{
		"threadId": 3,
		"threadName": "Swimming",
		"postCount": 67
	}
]

ERRORS:
N/A

======================================
POST /api/threads
======================================

Create a thread in the platform. ADMIN-ONLY

REQUEST:
Authorization: Bearer kljfdhsajkgdjsafd
Content-Type: application/json
{
	"threadName": "Gaming"
}

RESPONSE:
201 Created
{
	"threadId": 5,
	"threadName": "Gaming",
	"postCount": 0
}

ERRORS:
400 Bad Request
{
	"code": "VALIDATION_FAILURE",
	"message": "Validation failed",
	"fields": [
		{
			"field": "threadName",
			"message": "Thread name is required"
		}
	]
}

401 Unauthorized
{
	"code": "NOT_LOGGED_IN",
	"message": "Not logged in."
}

403 Forbidden
{
	"code": "NOT_AUTHORIZED",
	"message": "Not authorized to create threads."
}

======================================
PATCH /api/threads/{thread_id}
======================================

Rename a thread in the platform. ADMIN-ONLY

REQUEST:
Authorization: Bearer kljfdhsajkgdjsafd
Content-Type: application/json
{
	"threadName": "Not Just Gaming"
}

RESPONSE:
200 OK
{
	"threadId": 8,
	"threadName": "Not Just Gaming",
	"postCount": 0
}

ERRORS:
400 Bad Request
{
	"code": "VALIDATION_FAILURE",
	"message": "Validation failed",
	"fields": [
		{
			"field": "threadName",
			"message": "Thread name is required"
		}
	]
}

401 Unauthorized
{
	"code": "NOT_LOGGED_IN",
	"message": "Not logged in."
}

403 Forbidden
{
	"code": "NOT_AUTHORIZED",
	"message": "Not authorized to update threads."
}

404 Not Found
{
	"code": "THREAD_DOES_NOT_EXIST",
	"message": "Thread #{thread_id} does not exist."
}

======================================
DELETE /api/threads/{thread_id}
======================================

Delete a thread in the platform.
NOTE, comments and posts are also deleted
through thread deletion. ADMIN-ONLY

REQUEST:
Authorization: Bearer kljfdhsajkgdjsafd

RESPONSE:
204 No Content

ERRORS:
401 Unauthorized
{
	"code": "NOT_LOGGED_IN",
	"message": "Not logged in."
}

403 Forbidden
{
	"code": "NOT_AUTHORIZED",
	"message": "Not authorized to delete threads."
}

404 Not Found
{
	"code": "THREAD_DOES_NOT_EXIST",
	"message": "Thread #{thread_id} does not exist."
}
